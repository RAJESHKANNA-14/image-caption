# image-caption
This project generates natural language descriptions (captions) for images using deep learning techniques that combine Computer Vision and Natural Language Processing.

📌 Overview

Image Captioning is the task of describing the content of an image in words. This project uses a pre-trained CNN for feature extraction and an RNN/LSTM (or Transformer) for generating captions.

🚀 Features
Extracts image features using a pre-trained CNN (e.g., VGG16 / ResNet)
Generates captions using LSTM / Transformer models
Supports training on custom datasets
Evaluates captions using BLEU score
Easy-to-use inference script
